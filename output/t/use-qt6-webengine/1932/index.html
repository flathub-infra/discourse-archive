The webengine isn’t in the KDE 5.15 SDK either. It’s a separate baseapp to use it:

github.com

GitHub - flathub/io.qt.qtwebengine.BaseApp

Contribute to flathub/io.qt.qtwebengine.BaseApp development by creating an account on GitHub.

However it is missing Qt 6.2 support.
