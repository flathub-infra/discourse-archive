One of the libraries they use to package Chromium requires Flatpak 1.8.2. You can see this by checking
flatpak remote-info flathub com.github.Eloston.UngoogledChromium --show-metadata

You can install a later Flatpak version using the Flatpak PPA. In the terminal, run
sudo add-apt-repository ppa:alexlarsson/flatpak
sudo apt-get update
sudo apt upgrade
