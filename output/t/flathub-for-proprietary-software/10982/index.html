It is certainly possibly to publish proprietary software to Flathub.
Please note the following things though:

First, Flathub does not currently offer an payment service, nor does Flatpak has build-in DRM. If this is something you want, you need to provide it yourself in your software. A payment service is planned however, when all legal points have been cleared, so keep an eye out for announcements.

Second, for transparency towards the user, build manifests are provided publicly in the Flathub GitHub organization and builds are done by Flathub’s infrastructure.
For an proprietary app you can provide a pre-compiled archive, ideally a tar-archive, on a publicly accessible location, which the Build infrastructure can pull when building the Flatpak. So you don’t need to provide the source code.
Building the Flatpak on your own infrastructure and pushing that to Flathub is currently only permitted in rare cases.

Other than that, publishing an proprietary application is not that different than any other ones.
You can look at the documentation for more details:

docs.flathub.org
