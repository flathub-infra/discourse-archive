I ask because this is the recommended way:

./configure \
        --prefix='/usr' \
        --avformat-swscale \
        --enable-gpl \
        --enable-gpl3 \
        --enable-opencv \
        --enable-lumas \
        --qt-libdir='/usr/lib' \
        --qt-includedir='/usr/include/qt'

Also with these are the dependencies I use for archlinux:

  • ladspa
  • frei0r-plugins
  • libdv
  • sdl_image
  • libsamplerate
  • sox
  • ffmpeg
  • vid.stab
  • qt5-svg
  • jack

  • python
  • swig
  • movit
  • eigen
  • opencv

  • rubberband
