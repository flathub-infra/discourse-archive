Freedesktop SDK 26.08.0 released!

Sep 1, 2026
J
Javier Jardón
Sep 1, 2026 #1

Hi everyone,

The new Freedesktop SDK annual release is finally here!

Check the NEWS file for all the updates:
https://gitlab.com/freedesktop-sdk/freedesktop-sdk/-/blob/release/26.08/NEWS.yml

Main changes are:

  • Complete revamp of the documentation portal!! As always documentation is never completely done but we have spent some time trying to put different bits of docs together. Please check Home - Freedesktop SDK and report any issues / improvement / clarifications you think are needed
  • [BREAKING CHANGE] elements removed: glew, glog, pyelftool (replaced with python3-pyelftools), python3-pytz, python3-six, qpdf
  • unzip (which was carrying a lot of patches and looks very much unmaintained upstream) has been replaced by unzip from libarchive, a symlink is in place to work as a drop-in for most use cases.
  • Updates on all elements to the most recent versions
  • A lot of other fixes and improvements
  • These should not affect flatpak users, but put it in here for completeness
    • [BREAKING CHANGE] These elements are now private: git-minimal, vala-bootstrap, avahi-base, systemd-hwdb, lvm2-base, efitools-bin, python3-minimal, python3-build-bootstrap, python3-installer-bootstrap, rr, sbsigntools, cryptsetup-base, fwupd-efi, libsmbios, freetype-stage1, lvm2-stage1, bpf, gnu-efi, cmake-stage1, dbus-base, systemd-stage1, u-boot-qemu, cups-base, geoclue-base, shim, flex-base, glib-stage1, gobject-introspection-base, bluez-base, valgrind, polkit-base, systemd-base, apparmor-base, gamemode-base, u-boot-unmatched, pipewire-base, xdg-desktop-portal-base, avahi-base, ovmf, gcc-base, flat-manager-client-base, flat-manager-client-base
    • [BREAKING CHANGE] runtime-minimal.bst is now runtime-gnu.bst as a result runtime-minimal does not include bash or coreutils anymore, this allows replacing userland tools in bootstrap with alternative implementations. See #1950 for details
      Note: for components generating a kind: stack, and if the stack is missing a shell and utilities, you need to add runtime-gnu.bst there now too so the integration-commands can run.
      For more details, please see Choose Your Own Userland - Freedesktop SDK
    • [BREAKING CHANGE] Removal of snap support: as it was not highly used, we are happy to reintroduce it again if there is some demand for it

If you maintain an application using the Freedesktop SDK runtime, please consider upgrading the version, especially if you are still using 24.08 or earlier as It’s going to be EOL very soon (in the next weeks).

In most cases, this mostly requires changing “runtime-version” in the Flatpak builder manifest of the application.

This is the result of a year of work from all our contributors, thanks a lot to all of them!
