Things that you can do:

  1. you likely don’t need the SDK since this is just for building flatpaks, so you should be able to remove them. If you do then you should update the package

  2. if you try to uninstall org.gnome.Platform//3.32 and org.gnome.Platform//3.34, it will tell you which app still depends on it, and then you can ask the maintainers to update. If nothing depends on it, then you are good to go and remove them.
