Freeplane is not using that metainfo file, so updating screenshots there won’t do anything.

github.com/flathub/org.freeplane.App

org.freeplane.App.yml

  1. 
          
  2.   - mkdir -p /app/Freeplane /app/bin
    3. 
          
  3.   - cp -ra freeplane_bin/* /app/Freeplane

  7.   - ln -s /app/Freeplane/freeplane.sh /app/bin/freeplane
    8.

    10. 
          
  10.   - install -Dm644 debian-meta-data/freeplane.sharedmimeinfo /app/share/mime/packages/org.freeplane.App.mime.xml
    11. 
          
  11.   - install -Dm644 debian-meta-data/org.freeplane.App.metainfo.xml /app/share/metainfo/org.freeplane.App.metainfo.xml
    12. 
          
  12.   - install -Dm644 freeplane_framework/script/freeplane.svg /app/share/icons/hicolor/scalable/apps/org.freeplane.App.svg
