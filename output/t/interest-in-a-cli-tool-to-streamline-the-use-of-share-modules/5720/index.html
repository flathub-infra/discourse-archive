I really like the idea of shared-modules being the go to place for sharing modules, to prevent duplication of work, but I think it’s use could be streamlined a bit. I’d also like shared-modules to be advertised a bit more for people who are building Flatpaks. It seems like too much of a side thing currently.

I was wanting to make a CLI tool that would allow you to run something like flatpak-shared-module add <module>, and it would automatically download the module and add it to your manifest.

You could also run flatpak-shared-module update <module> or flatpak-shared-module update-all and it would pull the newest version.

Is anyone interested in this?
