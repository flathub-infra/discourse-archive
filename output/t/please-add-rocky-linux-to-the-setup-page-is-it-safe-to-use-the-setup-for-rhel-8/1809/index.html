Due to the end of the cycle of Centos 8 this year, I think it can be very useful… to add to Setup other distributions that will occupy that niche and can use Flatpak. The [instructions](https://www.how2shout.com/linux/install-flatpak-on-almalinux-or-rocky-8/) I used are the following: - Install Flatpak To install Flatpak on Rocky Linux, run the following in a terminal: $ sudo dnf install flatpak - Add the Flathub repository Flathub is the best place to get Flatpak apps. To enable it, run: $ sudo flatpak remote-add --if-not-exist flathub https://flathub.org/repo/flathub.flatpakrepo - Restart To complete setup, restart your system. Now all you have to do is install some apps. --- ![0_rockylinux-8 4](https://user-images.githubusercontent.com/68134588/141856174-1237405b-7f8e-4020-ae3b-ad0ba621fd4a.png) --- svg logo: [rockylinux 128px.svg.zip](https://github.com/flatpak/flatpak.github.io/files/7541756/rockylinux.128px.svg.zip) - Btw: [discourse.flathub](https://discourse.flathub.org/t/please-add-rocky-linux-to-the-setup-page-is-it-safe-to-use-the-setup-for-rhel-8/1809/2) related
