I think the wrong runtime gets set. flatpak-builder seems to take the last value which is in your case runtime: org.freedesktop.Platform.VAAPI.Intel but this is just a extension to the runtime. Remove all but runtime: org.freedesktop.Platform.

All the extensions you’ve listed already get downloaded & activated if the system requires them (see Freedesktop Platform metadata & Flatpak metadata under [Extension NAME]).

At least in my test flatpak fails with a similar error if the wrong runtime is set:

flatpak run --runtime=org.freedesktop.Platform.GL.default//23.08 org.gnome.Evolution
bwrap: execvp evolution: No such file or directory

If there’s still some issue you could try to run your application with flatpak run --verbose.
