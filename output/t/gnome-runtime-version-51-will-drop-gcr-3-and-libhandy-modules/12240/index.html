GNOME runtime version 51 will drop gcr-3 and libhandy modules

May 19, 2026
Y
Sabri Ünal
May 19, 2026 #1

Source: Upcoming GNOME 51 flatpak runtime will drop gcr-3 and libhandy

Hi,

These 2 libraries will be removed from GNOME 51 runtime (End of 2026); support for those will be still be available in GNOME 50 runtime which is meant to be supported until GNOME 52 is released (April 2027)

For GCR-3: Please move to GCR-4 (already in runtime) (or build it as part of your app if that is not possible)

For libhandy: please move to libadwaita (already in runtime) (or build it as part of your app if that is not possible)

Cheers
Javier
GNOME Release Team
