So, what kind of system do you use?

This is especially interesting in this case regarding the CPU. The app “Free Download Manager” is only provided to systems running Intel or AMD CPUs. If you have an ARM CPU, there is no build available for use. Same goes if you’re still on a 32-bit system.

If you’re on ARM, some other downloaders, such as Varia should be available.

Also, just to be sure: Is Flathub configured properly on your system? Just to check, if you run flatpak remotes, it shows an entry for Flathub? If not, follow the instructions on Setup Flathub first.
