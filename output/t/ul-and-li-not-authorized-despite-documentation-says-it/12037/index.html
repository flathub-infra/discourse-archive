Ok, I figured it out.

html-like nested tags don’t work like :

<p> A list :
  <ul>
     <li>A list item</li>
  </ul>
</p>

But

    as main tag will work :

    <p>A list:</p>
<ul>
  <li>An item</li>
</ul>
