Recently the Freedesktop SDK documentation has been completely reworked, and as part of it it received a new section targetting Flatpak application developers wanting to target the Freedesktop SDK runtimes. You can find it here: The Freedesktop Flatpak SDK.

While most of Freedesktop SDK’s documentation before that explained how to use it as a base to create you own OS or Flatpak runtimes, none explained how to consume it as-is, which is a shame as it is used as is, there are some applications on Flathub targetting its runtimes directly.

Could you please tell me and the Freedesktop SDK project what you think of that new section? What do you think is good about it? What is lacking?
