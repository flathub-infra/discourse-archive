Project information: While both Darktable and RawTherapee are available as standalone apps, neither one provides functionality needed by GIMP to be able to open CR3 and other raw formats.

This results in an error:

GIMP Message

Opening ‘/var/home/[FILEPATH].CR3’ failed: There is no RAW loader installed to open ‘Raw Canon’ files.

GIMP currently supports these RAW loaders:

  • darktable (http://www.darktable.org/), at least 1.7
  • RawTherapee (http://rawtherapee.com/), at least 5.2

Please install one of them in order to load RAW files.

I’m neglecting the template because the packages are already available but incompatible.

Also filed a ticket for Fedora here: 2358607 – Flatpak GIMP: "There is no raw loader installed"
