The ~/.var/app folder is where Flatpak itself stores application data & caches for each app, so each app can only see its own data. This is something of a special case among hidden folders. It’s like that by design, and I don’t know of an option that will let one application see the folders of other applications (although I’m not an expert in Flatpak settings, maybe there is one ).

If I run with the filesystem=host-os permission to get access to the mount command, I can see how it’s achieving this: ~/.var/app is mounted as a tmpfs, and then ~/.var/app/com.vscodium.codium is bind-mounted inside that.
