I’ve been thinking this for a while: why not have a Flatpak repo exclusively for mobile/smartphone apps? We can install desktop apps on Linux phones, however, there is no app store exclusively for mobile apps on Linux. Desktop apps don’t look good on a smartphone screen.
So why not create a new Flatpak repo like Flathub but for mobile apps? Its name could be something like Flatmob.
It would be a fork of flathub and it wouldn’t allow desktop apps.
I’m not sure how viable this is, but it’s just an idea
