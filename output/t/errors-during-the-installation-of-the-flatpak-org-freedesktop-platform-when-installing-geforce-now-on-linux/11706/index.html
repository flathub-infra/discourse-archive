Introduction
During the installation of GeForce Now, some users may encounter error messages similar to the ones below:

Aviso: Flatpak system operation Deploy not allowed for user
Erro: Falha ao instalar org.freedesktop.Platform: Flatpak system operation Deploy not allowed for user
ERROR: install_flatpak_app – Failed to install Flatpak app: org.freedesktop.Platform//24.08

Solution
Follow the steps below to resolve:

  1. Open the terminal and run the command below to manually install the necessary platform:
flatpak install org.freedesktop.Platform//24.08
  1. Try installing GeForce Now again.
