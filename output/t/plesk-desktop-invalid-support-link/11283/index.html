https://github.com/flathub/<FLATPAK_ID>/issues is the default issue URL for Flathub apps if none is explicitly defined in the app’s AppStream metadata. Apparently, the Flathub app repo maintainers have disabled GitHub issues for that repo.

I’ve opened a PR that sets the issue URL to https://forums.plex.tv/c/plex-players/computers/34 instead (which is the closest thing to an issue tracker I could find).
