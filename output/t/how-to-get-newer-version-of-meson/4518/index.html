I found that I can just install newer version of meson instead.


  - name: meson
    buildsystem: simple
    build-commands:
      - python3 setup.py build
      - python3 setup.py install --prefix=/app --root=/
    sources:
      - type: git
        url: https://github.com/mesonbuild/meson.git
        tag: '1.1.1'
