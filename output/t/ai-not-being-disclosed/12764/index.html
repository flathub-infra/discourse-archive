It is enforced during the submission process.

But it was never that new policies were applied retroactively to existing apps. Otherwise, there would be quite a few console apps, or apps not build from source, etc… having to be removed.

Also, and this is the main issue at hand:
Just enforcing the policies during submissions takes up time. Add to that there is active build moderation so that an update doesn’t add unwarranted permissions.

This is all done by a few volunteers who give their spare time to do a thankless work.
I would agree that making sure existing apps follow the rules for AI would be an good idea. But the resources are unfortunately very limited.

Apart from that, for a good disclosure of AI for existing applications you would need to expand the Appstream specification, so that software centers like GNOME Software can display this as well. And that is another thing that requires more effort than you would initially think.
