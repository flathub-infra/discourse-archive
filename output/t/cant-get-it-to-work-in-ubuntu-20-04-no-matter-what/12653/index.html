This is an issue with Ubuntu.

As an short summary: As the setup guide mentions, installing the Flatpak plugin for GNOME Software installs a second version of GNOME Software using the Debian package. However, the Snap version of GNOME Software is still installed.

The system gets the information what links an application can handle by a data file. Both the Debian version and the Snap version of GNOME Software have their own file. But Ubuntu is likely configured to give priority to the Snap version, which does not support Flatpak.

The easiest solution would be to uninstall the Snap version of GNOME Software, which should hopefully fix it.
Alternatively, you can use the drop down at the end of the install button on the Flathub website to get an installation command.
Or you can use an alternative client for Flatpak, such as Bazaar.

As a final note:
Ubuntu 20.04 is not supported anymore by security updates, you should not use it on a fresh installation. You should use the latest 26.04 version.
