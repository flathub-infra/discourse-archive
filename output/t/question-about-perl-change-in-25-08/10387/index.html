In SDK 25.08.0 release notes there’s the following change mentioned:

* [BREAKING CHANGE]: Perl modules now use major.minor versioned directories and no longer uses the patch version. PERL5LIB or PERLLIB variables may need to be updated.

My question is what do I need to update in the PERL5LIB variable that I use in my app’s build options? I use the following one: PERL5LIB: /app/lib/perl5/

Yes, you should be able to continue using that. If you previously used

PERL5LIB: "/app/lib/perl5/site_perl/5.40.2"

it should now be

PERL5LIB: "/app/lib/perl5/site_perl/5.40"
