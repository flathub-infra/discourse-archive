Don’t mix flapak and DEB it will probably not work, because this is now how flatpaks were designed.

Flatpak are designed to install only locale for current system defined language. I assume your current system language is currently not French.

  1. In Gnome set Settings | Region and Language | and change language to French.
  2. Logout and login again (or reboot if you prefer).
  3. In terminal: flatpak update -y will install “Locale” packages for your current system language for all flatpaks (including LibreOffice flatpak).
  4. Start a program e.g. LibreOffice and it is displayed in French.
