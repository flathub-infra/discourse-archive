I believe the runtime the current, up-to-date version uses, org.freedesktop.Platform//19.08, is not available for i386, and Flathub no longer builds i386 versions of apps, so whatever the last version for i386 was before the app moved to this newer runtime is the last version that will be available for 32-bit Intel systems.
