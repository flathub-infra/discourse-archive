Greetings Flathub community

Minutes ago, OBS Studio from Flathub Beta was updated to the RC3 release. This release candidate is interesting for us because it comes with obsproject/obs-studio#4552, which allows virtual cameras to work on Flatpaked OBS Studio!

It has the same requirements of non-Flatpak builds: you need to install the v4l2loopback module on your host system. Usually, distro packages call it v4l2loopback-dkms.

After installing the v4l2loopback module and restarting your computer, open OBS Studio and a new button should be available:
