This forum is for discussion for the Flatpak format and the Flathub distribution platform itself. If you need help with an specific app, please use the app-specific help channels. You can find them in the links section on the app page

That being said, there are a few things I want to mention:

nourishere:

I tried reinstalling rednotebook but that did not help.

The issue might be related to your user-data, which should be stored under ~/.var/app/app.rednotebook.RedNotebook. If you have a backup of that folder, you could try removing it to remove the user-data and see if the issue persists.

nourishere:

I also tried installing the journal module using pip once and using apt install python3-journal but both did not work.

If you have installed Rednotebook from Flathub (which I assume given you’re on the forum of it), it uses a separate Python environment and modules, which pip and apt don’t modify.
