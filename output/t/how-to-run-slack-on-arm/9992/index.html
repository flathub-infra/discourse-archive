There’s not really a way…

Slack is an proprietary app and only releases a x86_64 build. Since the source is not available, Flathub can’t build it for ARM.
That means its not possible to provide an ARM build for it.

The best course of action, even if quite implausible, would be that Slack would release an ARM build that can be packaged in a Flatpak. Or, even better, if Slack would itself publish the Flatpak in an official matter.

But its unfortunately outside of Flathub’s control.
