There exist arguments to not download or deploy an update, using the --no-pull and --no-deploy arguments.

However, you can also just run flatpak update. Before downloading any update, it will show you a prompt confirming the update. If you deny then by pressing n, you essentially viewed the update without running it.

Also, if you want to use the information in an program, you should probably take a look at libflatpak.
