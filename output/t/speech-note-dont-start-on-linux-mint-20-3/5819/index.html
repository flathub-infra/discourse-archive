I got a similar issue and fixed it after many tries with Claude! I installed SpeechNote on an old HP laptop with Intel GPU and 16Gb of RAM. At launch, it was loading constantly with a black screen without any hint. I fixed it by installing the NVidia addon with flatpak install flathub net.mkiol.SpeechNote.Addon.nvidia (it failed to install the AMD one, due to a lack of RAM). I hope this helps someone later on…
