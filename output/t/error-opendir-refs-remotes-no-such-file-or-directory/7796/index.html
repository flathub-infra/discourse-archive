Thanks to the help of someone in the Matrix room, I solved the problem by uninstalling all my Flatpak applications, removing the Flathub remote, uninstalling Flatpak itself, deleting the /var/lib/flatpak directory, reinstalling Flatpak, readding the Flathub remote and reinstalling all the applications.
