There are no runtimes released from Freedesktop SDK for RISC-V. That needs to be completed first. Setup native RISC-V builder (#1672) · Issues · freedesktop-sdk / freedesktop-sdk · GitLab Then GNOME needs to have RISC-V builders too. Having the hardware for Flathub is not enough unfortunately as without runtimes, no apps can use it. It becomes a chicken and egg problem then.

I suspect Flathub also needs additional storage capacity to host these as we ran out of disk space a few months ago.

It’s best to discuss this in RISC-V build enablement · Issue #4378 · flathub/flathub · GitHub
