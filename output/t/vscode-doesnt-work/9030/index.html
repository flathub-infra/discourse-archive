Replying to #3

You override the PATH environment variable which breaks the app sandbox (e.g. this fails, too: flatpak run --env=PATH=$PATH com.vscodium.codium).

  • If you add $PATH to the PATH override then flatpak does not expand this!
  • Make sure that you always add the default PATH, too: /app/bin:/usr/bin.
