I am also a Flathub newbie. I am by no stretch of the imagination qualified to give a definitive answer but this is what I do and I have not hit any issues so far.

  1. Download the reference file (as you already do)
  2. Scroll down to the command line instructions at the bottom of the page.
  3. Copy the first install command.
  4. Open the terminal and paste the command
  5. Hit the enter key on your keyboard.
  6. Enter your password and this should start the install.

You will be prompted to continue as authorization to download and install the file and dependencies is required by the system, it’s a simple ‘Y’ keypress.
