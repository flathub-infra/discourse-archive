Alright, so both Brave and LibreOffice had an regular update. Now, with GIMP, the update is about a dependency it uses.

As you may know, on Flatpak an app bundles its dependencies which are not in the runtime. So, if one of these dependencies are updated in the manifest, this results in a new build for the app, hence the update.

If you were to look into the repository of the GIMP manifest, you would see that the latest update was about graphviz library.
