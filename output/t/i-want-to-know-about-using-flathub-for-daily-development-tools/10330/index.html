In the end, it depends on what you want to do & what you’re comfortable with. There are several ways to build an application with a sandboxed IDE but it can require additional steps if native dependencies are involved.

I use IntelliJ IDEA & VSCodium & built everything inside the sandbox with the IDE Sdk & the Sdk extensions from Flathub (which already works for many projects because most languages provide their own package managers). If I’m missing anything, I build my own Sdk extensions to provide additional tools or missing dependencies or simply use the pre-built binaries of a project (e.g. Flutter or Android).

Some other options which I haven’t tried, yet:

  • Most IDEs have container support, so you can setup your build independent from Flatpak or the host system
  • You can start a host-terminal inside the sandbox via flatpak-spawn / host-spawn & use the terminal to build / run your project with your host system (if you’re running all from your host then you could also simply run a not sandboxed IDE)

Noteworthy, if it’s an option: GNOME Builder has very good Flatpak support. Besides using the host system or containers, it can use a Flatpak builder manifest to prepare everything required (but it’s been a while since I’ve tried it).
