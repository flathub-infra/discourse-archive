Not sure how your flatpak is setup and if you have the remote enabled, but you should be able to use the instructions on the arrow down install button GnuCash | Flathub

flatpak install flathub org.gnucash.GnuCash

then

flatpak run org.gnucash.GnuCash

Good luck
