The Stremio apps are not build for the ARM-Platform currently. The ARM-Build is disabled for in the manifest repository.

There is an open issue for enabling ARM-builds[1].

You could try to build the Flatpak from the manifest yourself, either by running Flatpak Builder directly on your Raspberry or by using the --arch=aarch64 argument.
