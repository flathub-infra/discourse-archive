Freedesktop SDK 20.08.0 released!

Aug 31, 2020
V
Valentin David
Aug 31, 2020 #1

Hello people,

We have now released Freedesktop SDK 20.08.0 on schedule. It is available
on Flathub.

If you maintain an application using the Freedesktop SDK runtime, please
consider uprading the version, specially if you were still using
18.08. In most cases, this mostly requires changing “runtime-version”
in the FlatpakBuilder manifest of the application.

If you have bugs with this new release, please report them to:

GitLab

Issues · freedesktop-sdk / freedesktop-sdk

A minimal Linux runtime

If you need assistance, you can join #freedesktop-sdk IRC channel on
Freenode. You can also contact us through the mailing list:
https://lists.freedesktop.org/mailman/listinfo/freedesktop-sdk

And finally you can also ask on Flathub’s forum:
https://discourse.flathub.org/
