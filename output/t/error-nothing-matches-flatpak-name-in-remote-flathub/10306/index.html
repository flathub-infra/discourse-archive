Flathub does not provide packages for 32-bit systems, only for 64-bit.

If possible, you should try if you can install a 64-bit system on your laptop. Unless your laptop is very, very old (think 2010 or earlier), its very likely it can run 64-bit. And there’s not really a good reason not to use 64-bit nowadays.
