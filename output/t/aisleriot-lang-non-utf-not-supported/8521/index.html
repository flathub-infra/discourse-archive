This probably doesn’t have anything to do with flatpak. The aisleriot RPM package would fail the same way if LANG is C.

It sounds like you simply need to set your locale correctly, see man localectl. On a modern system, it should always be a UTF-8 locale, and definitely not the fallback C locale.
