There’s an issue tracker specifically for the Zoom flatpak here: Issues · flathub/us.zoom.Zoom · GitHub . The Flatpak is maintained by volunteers, though, not by Zoom, so no-one can see or change Zoom’s source code to fix problems.

The other option is to ask on Zoom’s community forums, where you might get a response from someone who works for Zoom. But they don’t support using it in Flatpak, so this is generally only helpful if the same problem exists when you use their official packages. And even then, help is not guaranteed.
