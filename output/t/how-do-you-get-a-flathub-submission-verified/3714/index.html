Feb 9, 2023 #2

Requirement is you have edit access to the upstream domain specified in the Flatpak manifest.

Steps:

  1. Login to https://beta.flathub.org/
  2. Go to your Developer Profile
  3. Select the app you want to verify
  4. Start the verification process (it involves uploading a file to a URL on the upstream website)
