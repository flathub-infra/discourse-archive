jkgoose:

[…], I’m noticing this program only downloads the java edition from the google app store vs the microsoft bedrock edition. […]

By “this program”, I assume you’re referring to the Minecraft Bedrock Launcher?

First of all, this is not using a “java edition from the google app store”, since this doesn’t exist. The Java edition is separate, bought on Minecrafts website, and only available on desktop platform (though including Linux natively).
The Minecraft you find on the Google Play Store is the Bedrock edition, same as the one found on iOS or in the Microsoft Store.

Now, the “Minecraft Bedrock Launcher” is just a small wrapper to make the Android version of Minecraft Bedrock run on Linux. Using the Microsoft Store version would require a wrapper for a Windows version. So its not possible with the current launcher to use a version of Minecraft Bedrock bought on the Microsoft Store.

I’d assume you could login with your Microsoft Account in the game itself though, and transferring worlds should be possible by manually copying them.
