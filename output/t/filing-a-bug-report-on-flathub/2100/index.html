Filing a bug report on Flathub

Jan 22, 2022
C
Jorge O. Castro
Jan 22, 2022 #1

Thanks for helping out! The best way to track engineering work is to file issues on the Flathub repository on GitHub.

Problems like crashes, missing functionality, incorrect permissions, update requests and other “software bugs” should be reported on GitHub.

Each application has a separate repository, you can use the search in the repositories field to help narrow down where you should report the issue, just type the application you’re looking for:
