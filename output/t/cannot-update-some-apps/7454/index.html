Hi, is it not updating only this app or does it happen with other apps on flathub?

If it only happens with this app I would do the following steps:

  • check if the updates are disabled for this app from flatpak settings
    • You can check it with another app, Warehouse, that manages flatpaks

  • check if there’s some info in the docs, in it’s forum or in an issue about this topic
    • check if this update should be made inside the app and not by the flatpak
    • or someone else have the same problem
  • if you doesn’t find any info, ask this question in it’s forum, or if you think this is a bug, open a new issue following the repo guideline for bug reporting
