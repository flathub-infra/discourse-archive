There was an issue in the latest ostree release (a flatpak dependency) which results in this error:
Flatpak Update Command core dumped issue
Flatpak install/update fails with “Need more input” or “Input buffer too small”

This was fixed in an updated package. If you update your system & ostree to 2023.4-2 everything should work again.
