I don’t think it unarchives.

Usually, you don’t upload zip files to git repositories. So type git just pull that repo and does nothing with it, but the build system will try to find a cmake file, which isn’t there.

Youc could use type:archive and directly link the url to your github file, but not sure that’s better. I would prefer just pushing the unarchived contents into the git repo.
