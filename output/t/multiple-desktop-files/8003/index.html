Faugus:

org.faugus.faugus-launcher

Dash won’t work. Name the ID org.faugus.faugus_launcher

Flatpak

Requirements & Conventions

Flatpak deliberately imposes very few requirements on applications. However, a small number of standard Linux desktop conventions are expected, primarily to ensure that applications integrate with ...

Flatpak will export the following desktop filename patterns: $FLATPAK_ID.desktop, $FLATPAK_ID.foo.desktop, $FLATPAK_ID-foo.desktop.

So the second one will be org.faugus.faugus_launcher.shortcut.desktop
