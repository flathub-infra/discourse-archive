I’m running into the same issues with fltk-rs and my understanding is that gcc static libraries need to be built.

  • I don’t know if there’s another way to get gcc static libraries into Flatpak other than compiling
  • In order to build gcc to build you need mpc, gmp and mpfr
  • You’ll also need the llvm Sdk extension

I believe that a static build of gcc libraries will give you libsupc++.

You can find my current manifest here (not working yet, as gcc cannot find mpc libraries)

github.com/yveszoundi/entrusted-flatpak

flatpak/com.rimerosolutions.Entrusted.yml

main 
id: com.rimerosolutions.Entrusted

runtime: org.gnome.Platform
runtime-version: "48"
sdk: org.gnome.Sdk
sdk-extensions:
  - org.freedesktop.Sdk.Extension.rust-stable
  - org.freedesktop.Sdk.Extension.llvm20

command: entrusted
finish-args:
  - --socket=wayland
  - --socket=fallback-x11
  - --device=dri
  - --share=ipc
  - --env=FLATPAK=1

build-options:
  append-path: /usr/lib/sdk/rust-stable/bin:/usr/lib/sdk/llvm20/bin
  prepend-ld-library-path: "/usr/lib/sdk/llvm20/lib:/app/lib64:/app/lib"
