What could work is to download the archive with Flatpak-Builder and storing it to where CMake would download the archive to.
AFAIK if CMake already finds the archive downloaded it will just use that and not try to download it again.

That being said:
If you attempt to put it up to Flathub eventually, you will need to figure out how to build it from source:

docs.flathub.org
